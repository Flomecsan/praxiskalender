# Praxiskalender – Prototyp

Klick-Prototyp eines Praxis-Terminkalenders (Nachbau der samedi-Buchungslogik, Konfiguration Praxis Flintsbach).

**Öffnen:** https://flomecsan.github.io/praxiskalender/

- Alle Patienten sind **fiktive Testpatienten** (T1001–T1100), alle Termine Testdaten.
- Daten bleiben nur im eigenen Browser (localStorage); Zurücksetzen unter Einstellungen → Daten.
- Für einen realistischen Praxismorgen: Einstellungen → Allgemein → simulierte Uhrzeit setzen.
